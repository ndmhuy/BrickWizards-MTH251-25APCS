\subsection{Problem 14. Volumes by disks and shells}
A solid is obtained by rotating the region bounded by $y=x^{2}$, $y=0$, and $x=1$ about:
\begin{enumerate}[label=(\alph*)]
    \item The $x$-axis (use the disk/washer method).
    \item The line $x=2$ (use the shell method).
\end{enumerate}

\begin{enumerate}[label=(\alph*), start=3]
    \item Set up (but do not yet evaluate) the integral for the volume in case (a), then compute it.
    \item Set up and evaluate the integral for the volume in case (b). Simplify as much as possible.
    \item Compare the two methods (disks vs shells) in each case and explain which is more convenient and why. Would it still be the case if the region were more complicated?
\end{enumerate}

\subsection*{Strategy}
We are rotating the area under the parabola $y=x^2$ from $x=0$ to $x=1$ around $x$-axis and $x=2$ axis.
\begin{itemize}
    \item \textbf{Part (a):} We are rotating around the horizontal $x$-axis. Since the axis of rotation is a boundary of the region, we can slice perpendicular to the axis to obtain solid disks. The radius of each disk corresponds to the height of the function, $y=x^2$.
    
    \item \textbf{Part (b):} We are rotating around the vertical line $x=2$. For the shell method, we slice parallel to the axis of rotation to form thin cylindrical shells. The total volume is the sum of the volumes of these shells.
    \begin{itemize}
        \item The \textbf{radius} of a shell is the horizontal distance from the slice at $x$ to the axis at $2$, so $r = 2-x$.
        \item The \textbf{height} of the shell is simply the function value $y=x^2$.
    \end{itemize}
\end{itemize}

\textbf{(c) Volume about the x-axis (Disk Method)}
Since we are rotating around the $x$-axis, our cross-sections are vertical disks with thickness $dx$.
The radius of each disk is the distance from the x-axis to the curve: $R(x) = x^2$.

Using the disk formula $V = \int_{a}^{b} \pi [R(x)]^2 dx$:
\[ V_a = \pi \int_{0}^{1} (x^2)^2 dx = \pi \int_{0}^{1} x^4 dx \]
Compute the integral:
\[ V_a = \pi \left[ \frac{x^5}{5} \right]_{0}^{1} = \pi \left( \frac{1}{5} - 0 \right) = \boxed{\frac{\pi}{5}} \]

\textbf{(d) Volume about the line x=2 (Shell Method)}
Here, we use cylindrical shells. Since we are rotating about a vertical line $x=2$, the radius is horizontal.
\begin{itemize}
    \item \textbf{Radius ($r$):} Distance from a slice at $x$ to the axis at 2 is $r = 2 - x$.
    \item \textbf{Height ($h$):} The height of the shell is determined by the curve $y=x^2$.
\end{itemize}

Applying the shell formula $V = \int_{a}^{b} 2\pi r h \, dx$:
\[ V_b = \int_{0}^{1} 2\pi (2-x)(x^2) dx \]
Compute the integral:
\[ V_b = 2\pi \int_{0}^{1} (2x^2 - x^3) dx \]
\[ V_b = 2\pi \left[ \frac{2x^3}{3} - \frac{x^4}{4} \right]_{0}^{1} \]
\[ V_b = 2\pi \left( \left(\frac{2}{3} - \frac{1}{4}\right) - 0 \right) = 2\pi \left( \frac{8-3}{12} \right) = 2\pi \left(\frac{5}{12}\right) = \boxed{\frac{5\pi}{6}} \]

\textbf{(e) Comparison of Methods}
\begin{itemize}
    \item \textbf{Case (a):} The Disk method is more convenient here because the axis of rotation is right on the boundary, and the function $y=x^2$ is ready to calculate the radius of each disk. Trying to use Shells would be messy because we would have to switch everything to terms of $y$, which is just extra work.
    \item \textbf{Case (b):} The Shell method is the clear winner. We keep everything in terms of $x$. If we tried the Washer method, we would be slicing horizontally. That would mean finding an inner radius ($R_{in} = 2-\sqrt{y}$) and an outer radius ($R_{out} = 2$), squaring both, and integrating with respect to $y$. That's way more complex.
    \item \textbf{Conclusion:} Generally, if the function is given as $y=f(x)$ and we rotate around a vertical line, Shells are usually easier because we don't have to invert the function. If we rotate around a horizontal line, Disks/Washers are often the natural choice.
    \item \textbf{Extension:} However, with a complex composite shape like the one below, the Shell Method becomes inefficient. The geometry consists of multiple distinct parts stacked vertically, which would force us to set up many separate integrals if we used shells. The Disk Method is far more direct here.
\end{itemize}
